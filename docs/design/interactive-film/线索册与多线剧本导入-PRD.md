# 互动影游 · 线索册与多线剧本导入

产品评审稿 · 2026-11-20 · 适用范围为影策互动影游制作台、作品体检和观众播放器。本文承接[互动影游制作台 PRD](PRD.md)。下文描述拟议行为。

## 这次解决什么

《闭馆之后》的观众在第 6 秒翻过票根，到登记台时，可能已经忘记票背写的是谁。编剧面对另一个问题：手上已有带分支的完整剧本，进入新建页仍要走原著改编流程。本期让观众随时找回自己见过的证据，让作者把写好的跳转带进制作台，并给每次选择一个清楚的问题。

| 优先级 | 场景 | 交付边界 |
| --- | --- | --- |
| 首版 | 编剧导入已有分支剧本 | 粘贴或上传 UTF-8 TXT、识别场次与去向、逐条修正断链、确认后生成作品草稿 |
| 首版 | 导演配置提问 | 互动轨上编辑问题，连同选项和去向预览，保存后在视频与文字试玩中显示 |
| 首版 | 观众查线索、重选物件 | 本轮发现、当前携带、无剧透空态、暂停恢复、检查点回退 |
| 后续试验 | 按住完成一项动作 | 先在一个场次试作；成功、失败、超时各有可验证反馈，提供单击或键盘替代 |
| 后续评估 | 角色关系与专属片段 | 待有作品能提供关系变化前后的不同戏份，再验证观众是否主动重玩 |

小云雀的登录态入口区分单线和多线故事，示例故事树在选项旁标明目的分集。《小蜻蜓》观众版能查看行囊、往事、角色关系，还能按住潜行。本期采用前两项信息组织方式，把样片中的动作与好感玩法列为后续试验。调研只确认示例中的表现，通用作者配置能力尚待核实。

## 1　编剧从已有剧本开始

**入口与文字。** 在「新建影游」使用同级的「从小说改编／导入分支剧本」。原有小说流程继续使用原著、改编方向和模型选择。导入页给出可直接编辑的示例。作者粘贴文本或选择 TXT 后点「检查剧本」。首次识别采用本地明确格式，保留原作者文字。规则允许同一目的场被不同分支引用。

```text
[S01] 闭馆铃响
闭馆铃响，桌上放着一本登记簿。
- 打开登记簿 → E01
- 独自离开 → E02
[E01] 留下署名
她翻开登记簿，写下母亲的名字。
[E02] 合上木门
她把钥匙交还给管理员。
```

方括号中填写唯一场次编号，第一场为入口。普通文本是场次剧本，每条选项写成「文案 → 目标编号」。无出口为结局，一个出口为续播，两个及以上为选择。编号稳定，显示标题可以重名。导入只创建图和文字，互动锚点、媒体与携带条件由作者后续配置。

**核对与修复。** 核对页按原顺序列出编号、场名、剧本、选项和去向。找不到目标时显示原行、原编号和目标场选择器。重复编号、空标题、空剧本、格式错误、回环、孤立场次分别说明原因。修复映射后重新校验全图。允许返回编辑原文。再次编辑原文使上次核对失效，防止确认旧解析。空输入、解码失败、文件超过 40 MB 或原文超过现有 600 万字上限时，保留上一份可编辑内容并提示处理方式。

**确认。** 通过核对后，作者点「确认导入」。产品实现沿用新建影游保存入口，一次确认生成一份草稿，成功后进入新作品的制作台。生成失败保留原文和修复映射，允许重试；确认进行中禁用重复提交。退出未确认的导入需要保留当前草稿或询问是否放弃。已有作品的整图替换另行设计。

## 2　导演编写选择点的问题

在「制作台 → 场次 → 成片 → 成片互动轨」选中选择点，下方便可编辑「给观众的问题」。与触发时刻、限时默认项和片尾跳转共用当前轨道的保存动作。问题可留空，建议 1–60 字，最多 80 个 Unicode 字符；超出时保留输入并阻止保存。旧轨缺少此字段时沿用原来的选项布局。

作者视图同时列出**问题、行动、开放条件、目标场**。例如 S04 在第 4 秒问“你想给明天的展柜留下什么？”。选择录音机来路时，观众能选“播放修复者录音”和“交由家属暂存”。导演能从同一处切换围裙来路，核对另一条选项。玩家仅看到本轮可用行动。问题写入选择点，选项名称和去向继续引用剧情图里的出口。已有同一选择点的重复文本需由作者决定保留哪一份。

更换成片沿用待复核规则。互动轨和问题随作品版本一起保存。并发保存失败保留输入，供作者与服务器版本核对。文字走读显示相同问题、可用选项与线索反馈。进入结局后按实际到达的路线计数。

## 3　观众的线索册

**入口。** 播放器工具行提供「线索册」。桌面在右侧拉出抽屉，窄屏使用底部面板。打开后焦点进入面板，关闭或 Esc 返回入口；关闭后恢复打开前的播放与倒计时状态。原本暂停的视频继续暂停。切到后台、另一个弹层仍打开时继续冻结。面板里不展示总收集数、未发现的卡位或其他结局。

| 内容 | 写入时机 | 示例表现 |
| --- | --- | --- |
| 已发现的线索 | 实际翻看热点后按线索编号去重；带来路试演使用作者勾选的检查点状态 | 「旧票根」显示“票背写着陆青 · 五月十七”，标出来源「闭馆铃响」。错过票根时显示空态。 |
| 当前携带 | 选项的携带效果生效时更新，只显示当前物件 | 录音机和围裙各随本次选择出现。旧物件从当前携带中移除。 |
| 本轮状态 | 每场继承前一场状态；结局仍可查阅 | 从 S04 回退至 S01 第 16 秒，保留此前已翻看的票根，清除之后取得的物件。重新开始同时清空二者。 |

展示名可采用热点名称，说明使用发现时反馈，来源由场次关联。作者可提供简短收藏名（如动作“翻看票根”显示为“旧票根”）。无图时显示文本和通用图标。线索册随当前试玩会话保存；版本隔离和作品体检的历史记录继续沿用现行规则。辅助阅读按“名称、说明、来源”朗读；键盘可完成打开、切换、关闭和回退。

## 4　两个验证问题

1. **已有稿件能否直接使用？** 给编剧一份三场剧本，故意写错一个去向。观察能否独立定位并修正，再从两条分支进入对应结局。记录首次成功导入耗时、原文返工行数及失败原因。
2. **线索册能否帮助观众做决定？** 让首次观众翻看票根，选录音机，到登记台查看票背日期。观察能否找回日期、关闭后继续回答，以及是否能预测回退后会留下哪些东西。记录漏发现入口、倒计时误消耗、剧透和状态不符的次数。

## 5　交付验收

| 操作 | 可观察结果 |
| --- | --- |
| 从作品库新建，分别选两种起点 | 小说入口仍可生成改编方向；已有剧本进入输入及核对流程 |
| 粘贴示例，或上传相同 TXT | 两次核对的编号、文字、去向一致；共享目标只生成一个场次 |
| 给某选项填不存在的编号，随后修正 | 错误定位到具体行；修复后阻塞解除；新作品仅创建一次 |
| 引入回环、重复编号或不可达场次 | 可返回原文修复；提交前说明阻塞原因 |
| 修改 S04 提问并切换两种携带状态 | 两种状态共用问题，各自只展示本轮可用选项 |
| 票根窗口内点击、错过、回退重玩 | 分别获得、缺少、按检查点恢复线索；重复翻看只出现一次 |
| 剩余 5 秒时打开线索册，停留 10 秒再关闭 | 面板内计时冻结，返回仍约有 5 秒；正常超时走原默认项 |
| 回到第 16 秒改选围裙，再从头试玩 | 录音机消失；先前已见票根保留；从头开始后册中为空 |
| 在手机宽度、深色主题、键盘操作下走同一路线 | 面板、关闭键及选项可达；缩小视口后没有页面横向滚动 |

本轮交付为评审原型。导入确认在原型内生成核对结果，产品落地时再接入作品保存、冲突处理、文件限额和当前制作台。下一阶段的按住互动与角色关系需要单独验证其创作成本与可访问性。
